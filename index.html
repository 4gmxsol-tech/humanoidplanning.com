01 / THE PLANNING PROBLEM

Perception tells a robot what is there.
Planning determines what happens next.

Humanoid robots operate in open-ended environments where tasks unfold over multiple steps. A useful planning layer must decompose objectives, respect physical constraints, select actions, monitor outcomes and re-plan when reality changes.

02 / PLANNING STACK

A loop from intent
to execution.

The planning layer sits between high-level intent and low-level robot control, continuously incorporating observations and feedback.

01GoalWhat should be achieved?
02World ModelWhat is true now?
03Task ReasoningWhat sequence makes sense?
04Action PlanWhat should the robot do?
05MotionHow can the body execute it?
06FeedbackDid it work?
